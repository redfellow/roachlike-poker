## Approach
When `handoff` is set in `apps/web/src/main.tsx`, measure the sender and receiver `[data-seat-id]` panels and the play area with `getBoundingClientRect`, and pass the start/end offsets to `.handoff-card` as CSS custom properties (`--handoff-from-x/y`, `--handoff-to-x/y`). Rewrite `@keyframes table-handoff` in `style.css` to translate from the start offset to the end offset, shrinking into the panel, and delay the `seat--receiving` glow to the landing moment. Missing panels fall back to the current centre path. Kept in CSS so reduced-motion overrides continue to work unchanged. Under `.app--reduced` the card stays hidden and animations stay off, so `.app--reduced .seat--receiving` gets a static highlight instead, and the handoff state is held for the normal 1250 ms in both modes so the static highlight can be seen.
