## Approach
Store `icon: { shape: index, colour: index }` on the member record in `apps/server/src/runtime.ts` (and persisted room state in `store.ts` if members are persisted; default-assign on load when missing). Assign in the join path: pick the least-used shape among current members, then the first unused colour from a fixed palette (`as const`) for that shape. Expose it via `MemberView.icon` in `packages/protocol`. In `apps/web/src/main.tsx`, `Avatar` takes the icon (seats map `seat.personId` to the member) and drops `avatarColor`/`avatarVariant` name hashing; fall back to the hash only if no member is found. Server-side assignment keeps it identical for all viewers and stable across games, since members outlive games.
